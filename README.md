Calculatrice Web style iPhone

Un simple calculateur web inspiré de la calculatrice de l’iPhone.
Réalisé avec HTML, CSS et JavaScript, il permet d’effectuer les opérations de base avec une interface claire et intuitive.

Fonctionnalités : 

    -Design inspiré de l’iPhone
    
    -Boutons interactifs et fluides
     
    -Opérations de base : addition, soustraction, multiplication, division
    
    -Fonctions Effacer (C) et Supprimer (⌫)
    
    -Changement de signe (+/–)
    
    -Interface responsive

Technologies : 

      -HTML
    
      -Tailwind CSS
    
      -JavaScript
